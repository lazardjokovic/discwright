DiscWright 2.0 is the app rewritten from the ground up, as one program you install or simply run. It makes the same discs: the game's own icon and name in This PC, a menu when the disc goes in, and every disc read back after it is burned. What changed is everything around them.

## Download

- **DiscWright-2.0.0-setup.exe** installs it for you alone, with no administrator prompt, and adds it to the Start menu.
- **DiscWright-2.0.0-portable.exe** is the same app as one file. Put it anywhere and double-click it.
- **SHA256SUMS.txt** has the checksum of both, for `sha256sum -c`.

Windows 10 or 11, 64-bit. Nothing else needs installing.

**Windows will say "Windows protected your PC" the first time.** DiscWright is not code signed yet, so SmartScreen does not know it. Press More info, then Run anyway. On a new Windows 11 machine with Smart App Control turned on it will not start at all until it is signed, which is planned.

## Already using the PowerShell DiscWright?

Installing 2.0 upgrades it in place: the same Start menu entry, the same place in Apps, now the new app. Discs you made before still work exactly as they did, since the disc does not depend on the program that made it. A project file saved by the PowerShell version is recognised and refused by name, because its menu settings do not carry across; add the game again and choose the look here.

The PowerShell version is still there for anybody who wants it, on the [powershell branch](https://github.com/lazardjokovic/discwright/tree/powershell), as DiscWright (PowerShell).

## What is new

**Any disc of a set installs the whole set.** Press Install disc 1 of 2 and a page asks where the installer should be put back together, suggesting the drive with the most room and saying how much it needs. The menu copies the disc, opens the tray, asks for the next one and carries on by itself when it arrives. It joins and checks any file that was cut across discs, starts the game's own installer, and afterwards says Play and offers to remove the copy it made. The manual and the extras ride every disc, so whichever one somebody picks up has them.

**GOG patches are read against the installer.** A patch the installer already covers arrives unticked with the reason beside it, so a disc does not carry hundreds of megabytes it will never use. The rest fold into one Update button on the menu, which runs them oldest first.

**Everything happens in one window.** Add a game by dropping its folder on the window. The artwork, music, manual and extras are chosen in one panel. The menu can be seen before anything is built. Building and burning show how far they have got, with a percentage, and the window never freezes while they work.

**Burning reads the disc back with a percentage that moves**, even inside a big file, and reads a file a second time before counting it as bad. A worn rewritable that one drive cannot read is named for what it is, with the drive, rather than called the wrong disc.

**The app keeps a log.** Open the log, under the version line, opens today's: what the drives said, every question and its answer, and every file a disc failed to read back. It stays on your PC, a fortnight at most. If something goes wrong, it is the file to attach to an issue.

**Start Here.hta can be left off** under More options, for discs going to machines where AutoPlay works.

**It follows Windows' light or dark mode**, title bars included.

## Not in 2.0

- **Burn with...**, which handed the image to another burning program. DiscWright burns and checks the disc itself, and any other program can burn the ISO it writes.
- **The Linux naming** of a disc, and per-game manuals and extras on a disc of several games.
- **winget** follows a little after this release, as the next version of the same package.

## Checked how

The suite is 1785 tests, run on every change. A stateful walk presses the window's buttons in random orders and checks after every step that the window still adds up. Faults are planted on purpose to prove the tests catch them. Sets were burned to real CD-Rs and CD-RWs, in two drives, and the game installed from them through the menu. The installer was tested on a clean Windows 11 machine over the PowerShell version, beside it, and on its own.
