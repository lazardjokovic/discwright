DiscWright 2.0.2 fixes what burning and installing sets on an older laptop turned up: a window too tall for its screen, a menu that froze and stood at 0%, and a disc menu that garbled any name with an accent in it.

## Updating

From 2.0.1, press **Check for new version** under the app's name, then **Update to 2.0.2**. From 2.0.0, download the setup below and run it; it installs over 2.0.0 in the same place.

**The fixes to the disc's menu are on discs built with 2.0.2.** A disc built before keeps the menu it was built with. Build it again to give it the new one.

## Download

- **DiscWright-2.0.2-setup.exe** installs it for you alone, with no administrator prompt, and adds it to the Start menu.
- **DiscWright-2.0.2-portable.exe** is the same app as one file. Put it anywhere and double-click it.
- **SHA256SUMS.txt** has the checksum of both, for `sha256sum -c`.

Windows 10 or 11, 64-bit. Nothing else needs installing.

**Windows will say "Windows protected your PC" the first time.** DiscWright is not code signed yet, so SmartScreen does not know it. Press More info, then Run anyway.

With winget, `winget upgrade DiscWright.DiscWright` once this version reaches it.

## The disc's menu

**Names with accents and symbols show as they are.** A game called Café, Pokémon, STAR WARS™ or Đorđe came out as a row of odd characters in its menu's title, because the menu was read in an older Windows encoding. The Install button of a set said "Starting" followed by three of them. Every character now reads the same on every Windows.

**A set installs from its menu however the menu was opened.** Opened by double-clicking it in Explorer rather than by AutoPlay, the menu of a set said its files would not copy and that the disc may be scratched. The disc was fine.

**The copy shows how far it really is.** Copying a big file used to sit at 0% until the file was done. The menu now asks Windows how much has been read and the bar follows it. The disc check is still an estimate, but it no longer judges the drive by the small files read while it spins up, so it moves through a big file too.

**It does not freeze when the next disc goes in.** While a set waited for its next disc, the menu could go "Not responding" for a moment as the new disc spun up. It now looks at the disc without waiting for it.

## The app

**The window fits a smaller screen.** It opens no taller than the screen has room for, and it can be made shorter by dragging its edge. It keeps its width, so its list of files stays lined up. The artwork window fits the same way.

**After a burn it says what it is waiting for.** Between writing a disc and checking it, the window went on saying "flushing the drive's buffer" for minutes. It now says it is waiting for the disc to come back, then how long the drive has spent reading it back in. The question asking you to push a laptop drive's tray shut is in the log with every other question.

**A file moved after it was chosen is named.** Choosing a picture or a manual and then moving it made the preview say "Something went wrong" and nothing useful. It now says which one is not where it was chosen from, and to choose it again.

**The disc face is shown as a disc.** Under Artwork, music and extras, the picture for printing on the disc is shown round, with its hole, the way it will be printed. The file itself stays square, which is what disc printing software takes.

**The log follows an update.** Every step of updating from the app is written in the log: what was downloaded, how big it was, whether its checksum matched, and why it stopped if it did.

## Checked how

The suite is 1905 tests, run on every change. The menu's encoding was checked by previewing a game named with an accent, a trademark sign and Serbian letters on a clean Windows 11 machine, garbled in 2.0.1 and right in 2.0.2. The copy's progress was measured there first, and a real copy is watched the way the menu watches it every time the suite runs.
