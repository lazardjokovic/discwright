DiscWright 2.0.3 is the version going to the Microsoft Store. It also fixes four things xniwo found testing 2.0.1, and stays sharp on every screen, whatever scale Windows sets it to.

## Updating

From 2.0.1 or 2.0.2, press **Check for new version** under the app's name, then **Update to 2.0.3**. From 2.0.0, download the setup below and run it; it installs over 2.0.0 in the same place.

## Download

- **DiscWright-2.0.3-setup.exe** installs it for you alone, with no administrator prompt, and adds it to the Start menu.
- **DiscWright-2.0.3-portable.exe** is the same app as one file. Put it anywhere and double-click it.
- **SHA256SUMS.txt** has the checksum of both, for `sha256sum -c`.

Windows 10 or 11, 64-bit. Nothing else needs installing.

**Windows will say "Windows protected your PC" the first time.** DiscWright is not code signed yet, so SmartScreen does not know it. Press More info, then Run anyway.

With winget, `winget upgrade DiscWright.DiscWright` once this version reaches it.

## What is new

**Dragging games in adds them once.** Dropping folders onto the list added every one of them twice, so ten games meant ten "already on the disc" boxes, and the question about a folder of games seemed to come back after it was answered.

**The cross that takes a game off the list stays in reach.** With enough games for the list to scroll, it was hidden under the scrollbar on every row.

**A disc of many games shows all of them.** Its menu's list of games now scrolls, where it used to cut off after about seven, and that screen has an Exit. The fix is on discs built with 2.0.3.

**Every option under More options says what it does** when you point at it, the list of what every file should be among them.

**Sharp on every screen.** DiscWright now tells Windows it draws itself for each screen's own scale. Dragged from a laptop's screen onto a monitor set to a different scale, the window is drawn again at that scale instead of being stretched and going soft.

**Ready for the Microsoft Store.** The same app is on its way to the Store. A copy installed from there is kept up to date by the Store, so it never updates itself and makes no connection of its own: its link under the app's name says **See it in the Store**. It keeps its log where Windows keeps a Store app's files, and Open the log still opens it. Copies from here and from winget work exactly as before.

**A privacy page.** [discwright.com/privacy](https://discwright.com/privacy/) says what DiscWright keeps on your PC and the only times it uses the internet. In short, it collects nothing.

## Checked how

The suite is 1925 tests, run on every change. Microsoft's own certification kit passes the Store package, and that package was installed on a clean Windows 11 machine and started the way the Store starts an app: it knew it was the Store's copy, its link opened the Store, its log opened, and its disc menu preview worked.
