DiscWright 2.0.1 can update itself, says plainly when a game needs more than one disc, and shows the check after a burn moving from the start.

## Coming from 2.0.0? Install this one by hand

2.0.0 has no Update button, so this once, download the setup below and run it. It installs over 2.0.0 in the same place, and your discs and projects are untouched. From 2.0.1 on, the app updates itself when you ask it to.

## Download

- **DiscWright-2.0.1-setup.exe** installs it for you alone, with no administrator prompt, and adds it to the Start menu.
- **DiscWright-2.0.1-portable.exe** is the same app as one file. Put it anywhere and double-click it.
- **SHA256SUMS.txt** has the checksum of both, for `sha256sum -c`.

Windows 10 or 11, 64-bit. Nothing else needs installing.

**Windows will say "Windows protected your PC" the first time.** DiscWright is not code signed yet, so SmartScreen does not know it. Press More info, then Run anyway.

With winget, `winget upgrade DiscWright.DiscWright` once this version reaches it.

## What is new

**Update from the app.** Press Check for new version under the app's name. When there is a newer one, the installed app offers **Update to** it: it downloads the release's installer, checks it against the checksum the release publishes, then closes, updates and opens again by itself, keeping the folder and the choices of the first install. It only ever does this when you press it, never while a disc is being built, burned or erased, and never with a file that does not match its checksum. **What's new** beside it opens the release page. The portable exe offers the release page as before, since it has no installer to run.

**It says when the disc you chose means more than one.** A game bigger than the disc but with no file bigger than the disc becomes a set with whole files on each disc. The line under Split a file too big for one disc now says **Needs 2 discs** whenever that happens, with the box ticked or not. Before, it said nothing would be cut, which was true and read as though it all fit.

**The check after a burn moves from the start.** Reading a disc back used to sit at 0% while a CD spun up and then jump. It now moves after the first megabyte, and the log shows it climbing rather than only the start and the end.

## Checked how

The suite is 1841 tests, run on every change. The update was watched on a clean Windows 11 machine: an older build found the real 2.0.0 release, downloaded it, matched its checksum, installed it and was replaced, with no Windows warning on the way, and a newer installer started the same way opened the app again by itself.
